# Paradise Nursery Shopping Application

## Project Overview
Paradise Nursery is an online houseplant shopping application built with React and Redux Toolkit. It helps users explore houseplants, view prices, add products to a shopping cart, and manage their selections.

## Features
- Attractive landing page with a background image
- Company information section
- Three houseplant categories with six products each
- Plant images, names, and prices
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease product quantities
- Remove products from the cart
- Automatic item and total price calculation
- Checkout placeholder displaying “Checkout Coming Soon!”
- Continue Shopping navigation

## Technologies Used
- React
- Vite
- JavaScript
- CSS
- Redux Toolkit
- React Redux

## How to Run the Project
1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL displayed in the terminal.
